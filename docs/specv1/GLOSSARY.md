# Glossary

- **Evidence quality:** ordinal assessment of source coverage, freshness,
  representativeness, and QC. It is not a probability.
- **Scenario spread:** variation across explicitly defined model members,
  forecast cycles, or nowcast trajectories. Families remain labelled.
- **Source disagreement:** conflict between independent or differently issued
  evidence sources.
- **Planning score:** explainable ranking utility from 0–100. It is not a
  calibrated probability of seeing an event.
- **Evaluation revision:** immutable bundle of inputs, algorithms, site set,
  valid-time interval, manifests, and rules used for a result.
- **Frame key:** one valid time within an evaluation revision.
- **Plan snapshot:** signed, immutable, renderer-neutral recommendation bundle.
- **Line-of-sight cloud proxy:** modelled cloud evidence intersected with the
  viewing ray. It is not a claim of full 3-D cloud truth.
- **Access approved:** current evidence supports lawful entry, stopping,
  parking, opening hours, and required safety checks.
- **Origin stay option:** the user-provided location evaluated for obstruction
  and safety without treating the user's lawful private location as a public
  destination.
