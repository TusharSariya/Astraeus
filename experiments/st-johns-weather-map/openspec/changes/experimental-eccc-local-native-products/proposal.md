# Experimental ECCC local native products

Acquire immutable native XML for six named Avalon-relevant partner SWOB stations and the English St. John's city page, with finite request and artifact bounds. Preserve every native element disposition, provider identity, observation/issue time, original unit, missing-value presence, native qualifier and partner attribution without canonical mapping.

MetNotes remains an observed-empty success at discovery. If a payload reappears, refuse it before payload retrieval until its complete size and schema are captured under a separate reviewed bound.

No adapter is registered or scheduled. Every acquired run uses `manifest_unresolved`, remains `complete: false`, `operational: false`, and has no normal API publication. Partner redistribution terms, SWOB QA-code meaning, city forecast-period/coded-condition semantics, and a native XML delivery route require owner contracts first.

Spec-Impact: experiment only; no normative transition or product admission.
