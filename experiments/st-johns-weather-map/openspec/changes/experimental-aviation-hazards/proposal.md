# Experimental aviation hazards and reports acquisition

## Scope

Acquire bounded, immutable native artifacts for official AWC SIGMET/AIRMET and
PIREP/AIREP, ECCC IWXXM SIGMET/METAR/TAF, selected WMO aviation bulletins, and
ADSB.lol Mode-S weather only after source semantics and permission/geography
are independently established. Existing AWC METAR/TAF JSON and raw aircraft
position tracking are excluded.

Every source remains nonpublishable until an owner-approved field, unit, time,
quality, geographic-eligibility, manifest, and API contract exists.

Spec-Impact: experiment; no normative status transition.
Spec-Refs: GOV-SPEC-001, GOV-SPEC-002, GOV-SPEC-004, GOV-SPEC-005, GOV-SPEC-006
