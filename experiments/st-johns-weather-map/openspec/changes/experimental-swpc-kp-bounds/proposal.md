# Experimental SWPC Kp allocation bounds

Bound the already registered SWPC Kp observed and forecast acquisition before
either payload-bearing request. Decode and normalize every row in a Linux child
with enforced address-space and single-file limits. This is an experimental
implementation under the accepted capacity policy; it does not change a
normative status.
