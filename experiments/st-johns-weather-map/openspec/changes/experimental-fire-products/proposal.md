# Experimental fire-product acquisition

## Scope

Acquire CWFIS public WFS hotspot snapshots, dated daily hotspot CSV, and dated
CFFEPS CSV as nonpublishable source artifacts. Preserve their documented native
properties and header fields without assigning canonical fields or a fire-risk
meaning.

NASA FIRMS MODIS/VIIRS APIs require a MAP_KEY. This experiment does not seek,
read, or use a credential; that product remains explicitly permission-gated.
Standalone FireWork is superseded; BlueSky has no verified documented machine
feed and remains excluded.

Spec-Impact: experiment; no normative status transition.
Spec-Refs: GOV-SPEC-001, GOV-SPEC-002, GOV-SPEC-004, GOV-SPEC-005, GOV-SPEC-006
