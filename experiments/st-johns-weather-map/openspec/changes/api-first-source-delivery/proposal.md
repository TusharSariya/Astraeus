September 7 instruction to implement the supplied API-first plan. This records
the user's selected scope, not an agent approval or V1 status transition.

The owner explicitly requested preserving existing routes and evidence models,
formalizing source/product/field/variant/level/run/location/time identity,
declarative capabilities, generated Pydantic/OpenAPI/TypeScript contracts,
shared deterministic fixtures, and a narrow source interface proved by GFS and
AQHI. The same instruction authorizes selected-model AQHI observation companions
and supported GFS run selection. Earlier companion proposal approval requests
are superseded for that exact named observation behavior.

remain authoritative. API shape is additive and backward compatible. Source
workers own acquisition; the orchestrator owns shared integration. Only passing
reviewed changes are integrated, with fixture proof distinguished from live proof.

experimental point path using the existing composition adapter's field, unit,

isolated-only delivery restriction for this bounded point path. It does not
register background ingestion, assign a producer run, promote display-primary
admission or admit other composition fields.

contract conflict and is held for the explicit owner answer. This authorization
