## ADDED Requirements

### Requirement: Experimental air-quality publication does not imply scientific admission
An accepted canonical field contract MAY permit a separately reviewed experimental normal-route readback. It SHALL NOT by itself authorize source scheduling, operational status, display-primary selection, AQHI derivation, health advice, model/analysis blending, smoke causality, or production admission. Until implementation is accepted and verified, source-scoped raw variables SHALL remain absent from normal point responses.

#### Scenario: Canonical contract is accepted before implementation review
- **WHEN** the owner accepts the field and phase vocabulary but no conforming runtime change has merged
- **THEN** existing RAQDPS and RDAQA acquisition remains nonpublishable and normal API behavior is unchanged
