# Astraeus

Astraeus is an astronomical observation planner that synthesizes selected-
subject geometry or forecasts, weather, observations, visibility, site access,
obstructions, equipment needs, and travel into a decision-oriented
recommendation. It uses planning scores rather than claiming an uncalibrated
success probability.
